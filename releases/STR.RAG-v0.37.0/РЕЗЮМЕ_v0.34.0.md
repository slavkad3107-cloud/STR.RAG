# STR.RAG v0.34.0 «Choice»

Дата: 26.07.2026. Главное: **приложение само находит рабочий ИИ** и больше не
зависит от одного провайдера.

## Что было не так
Все 75 ответов приходили пустыми: в поле ключа DeepSeek оказался **ключ Cohere**
(в ТЗ они идут подряд — при копировании слиплись), API отвечал `401 … ****KYo2
is invalid`, а запасного провайдера не было. Плюс DeepSeek переименовал модели,
а у Google `gemini-2.5-flash` перестала выдаваться новым ключам (404).

## Что сделано

### 1. Все провайдеры из ТЗ подключены (11 штук)
DeepSeek, OpenAI, Gemini, Anthropic, Kimi, Mistral, **Cerebras, Groq,
OpenRouter, Cohere** и локальная Ollama. Ключи разложены по своим переменным в
`.env` и **едут вместе с базой** («📤 Выгрузить базу» / «📥 Забрать базу»), а при
запуске подхватываются из папки переноса автоматически.

### 2. Проверка при запуске + автовыбор лучшего
Приложение опрашивает провайдеров (≈10 c, параллельно) и **проверяет реальной
мини-генерацией**, а не списком моделей — список врёт: модель может числиться,
но отдавать 404/429. Порядок выбора:

1. локальная Ollama — бесплатно и приватно (если модель ≥13B; мелкая 7B уступает
   облачным по качеству и уходит ниже);
2. бесплатные облачные — Gemini, Mistral, Cohere, OpenRouter;
3. DeepSeek — платный, но дешёвый;
4. дорогие (OpenAI/Anthropic) — в последнюю очередь.

Статус видно в сайдбаре: «🩺 Провайдеры» — таблица «работает / лимит исчерпан /
нет средств / недоступно из страны» и кнопки «Проверить все», «Выбрать лучший».

### 3. Цепочка запасных вместо одного резерва
Если основной провайдер упал посреди прогона (лимит, ключ, сеть) — ответы
продолжаются на следующем рабочем по тому же ранжированию. Раньше падал один —
падали все 75 ответов.

### 4. Порядок в папках
- **Код** — в папке разработки (там же GitHub-репозиторий).
- **`STR.RAG`** — только витрина: `releases/STR.RAG-vX.Y.Z/` и `РЕЗЮМЕ_*.md`.
  Запуск — `releases\STR.RAG-v0.34.0\run.bat`.

### 5. Мелочи
- Ключ не принимается, если это не ключ (пробелы/перенос строки/SSH) — прежний
  не затирается.
- Убрано предупреждение Streamlit про `sb_model_default`.
- Gemini переведён на OpenAI-совместимый эндпоинт (пакет `google-generativeai`
  снят с поддержки).

## Как обновиться
`releases\STR.RAG-v0.34.0\run.bat`. **install.bat не нужен** — зависимости не
менялись. 45 юнит-тестов зелёные.
